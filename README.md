# TouchRotate
Rotate your Windows touchpad controls to match your screen orientation(For Windows Only)

it keeps the touchpad intuitive to use, so you don't have to fight your cursor when your laptop is in an unusual orientation coded in **python** (easy to use)

### REQUIREMENTS:
*Python 3 on Windows. No pip installs needed (uses only
the standard library's ctypes)

## How To Use
Download [Python](https://www.python.org/downloads/windows/) and run the script directly in python.
**or**
open commandline/terminal/console in the folder where you downloaded the .py file and run `py TouchRotate.py`

### SAFETY:
closing this console (or Ctrl+C) immediately restores normal
Windows mouse behavior - the raw input takeover is tied to this
process and Windows cleans it up automatically when the process ends.
